# 행성 착륙 미션 — 우주선 꾸리기

처음 받은 예산 200억 원으로 우주선을 꾸려 행성까지 날아가 착륙하는 시뮬레이션 게임입니다.
예산은 회차마다 이어져요. 성공해서 번 보상으로 더 좋은 우주선을 만들어 더 어려운 행성에 도전하세요.
`index.html`을 브라우저로 열면 바로 할 수 있어요.

## 게임 순서

1. **미션 준비** — 행성, 선체 재료, 선원 수, 산소·음식, 수리도구, 연료를 고릅니다. 합계가 가진 예산보다 많으면 발사할 수 없어요. 발사하면 비용이 예산에서 빠져요.
2. **여정** — 하루가 지날 때마다 선원이 산소 1 kg, 음식·물 2 kg을 쓰고, 궤도 수정에 연료 30 kg을 씁니다. 무작위로 고장이 나고, 수리도구가 있으면 고칩니다.
3. **착륙** — 직접 조종(스페이스/↑ 키 또는 엔진 버튼)이나 자동 조종으로 내려갑니다. 도중에 `A` 키로 바꿀 수 있어요.
4. **결과** — 성공하면 보상이 예산에 더해져요.

## 예산과 보상

- 처음 예산은 **200억**. 회차마다 새로 충전되지 않고 그대로 이어져요.
- 예산이 바닥나서 가장 싼 발사(알루미늄 선체 + 선원 1명 = 9억)도 할 수 없으면 **지원금 100억**이 자동으로 들어와요.
- 성공 보상 = 기본 보상 + 절약 보너스 + 탐사 보너스
  - **기본 보상**: 행성 난이도에 따라 10억 ~ 10조
  - **절약 보너스**: 기본 보상 × (100억 − 쓴 돈) ÷ 100억. 30억을 쓰면 +70%, 100억 이상 쓰면 0%
  - **탐사 보너스**: 살아남은 선원 1명당 기본 보상의 10%
- 화면 오른쪽 위 **처음부터** 버튼으로 예산과 기록을 처음 상태로 되돌릴 수 있어요.

## 규칙

| 항목 | 내용 |
| --- | --- |
| 선원 | 1~10명, 1명당 3억 · 300 kg. 많을수록 수리 성공률이 높아요 (50% + 10%×인원, 최대 95%) |
| 산소 | 떨어지면 선원이 모두 숨져요 |
| 음식·물 | 떨어지고 3일 뒤부터 하루에 1명씩 숨져요 |
| 수리도구 | 1개 1.5억. 고장 1번에 1개씩 쓰고, 실패하면 1개 더 써요. 없으면 고장의 피해를 그대로 받아요 |
| 연료 | t당 0.5억. 도착할 때 연료가 없으면 추락해요 |
| 고장 | 산소 누출, 식량 부패, 연료 누출, 선체 균열, 엔진 손상 |

### 행성

달, 수성, 화성, 타이탄, 금성과 가상의 행성 3개(아쿠아-9, 헤비론, 인페르노), 그리고 중력(0.5~30 m/s²)·대기 밀도(지구의 0~100배)·여정(1~200일)을 직접 정하는 행성이 있어요.
난이도는 중력, 대기, 거리로 계산하며 보상은 `10억 × 10000^(난이도^1.5)` 입니다.

## 물리 모형 (단순화)

- 위아래 1차원 운동. 중력, 엔진 추력(2,000 kN, 비추력 340초), 공기저항.
- 대기는 고도 7.2 km마다 약 2.7배씩 옅어지고, 땅의 기압 = 대기 밀도 × 중력 ÷ 지구 중력.
- 공기 마찰열은 Sutton–Graves 식에 게임용 배율(×14)을 곱해 계산하고, 표면 온도가 재료의 내열 온도를 넘으면 선체가 상해요.
- 짐이 무거울수록 같은 엔진으로 감속이 느려집니다 (추력 ÷ 무게).
